Input

Usage

Form control setup

All form components in the library are fully compatible with reactive forms. You can easily pass custom validators to the form controls, and even customize the validation messages to suit your needs.

Passing custom error messages

Error messages can be passed to the form control using the customErrorMessages with a type of Record<string, string>. See the example on the right.

Properties

Parameter Required Accepted values Usage
id

Required

 string

Accepts a unique identifier for the form control.
formControlName

Required

 string

Accepts a form control name from either your form group or your single control

label

Optional

 string

Accepts a label for the form control.
placeholder

Optional

 string

Accepts a placeholder for the form control.
size

Optional

 compact|default

Controls input sizing. "Compact" has less padding, "default" follows the standard theme.

shape

Optional

 pill|curve|default

Defines the input shape. "Pill" is a fully rounded input, "curve" has rounded corners, and "default" is a classic square-cornered input.

icon

Optional

 string

Specifies a Font Awesome class for the input's icon (e.g., fa-plus).

iconPosition

Optional

 left|right

Sets the icon's position relative to the input text. Defaults to "left".

autoComplete

Optional

 string

Accepts an autocomplete attribute for the form control. Defaults to off.

zenClass

Optional

 string

Allows overriding default styles by passing Tailwind CSS classes. Utilize the ngx-zen/tailwind plugin to target specific elements within the alert component.

customErrorMessages

Optional

 Record<string, string>

Accepts custom error messages for the form control. Defaults to automatically generated error messages.

Zen Classes

Prefixes Usage
input

Accepts Tailwind CSS classes for the input, e.g., input:bg-red-500. Some classes may need to be forced with an exclamation mark !, e.g., input:!ring-red-500.

label

Accepts Tailwind CSS classes for the label, e.g., label:bg-red-500. Some classes may need to be forced with an exclamation mark !, e.g., label:!ring-red-500.

error

Accepts Tailwind CSS classes for the error, e.g., error:bg-red-500. Some classes may need to be forced with an exclamation mark !, e.g., error:!ring-red-500.
