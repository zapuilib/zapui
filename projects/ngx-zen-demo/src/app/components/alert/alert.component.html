Properties

Parameter Required Accepted values Usage
type

Optional

 success|error|info|warning

Specifies the type of alert to be displayed. It affects the color scheme and icon based on the value (e.g., green for success, red for error).

variant

Optional

 classic|default

Defines the visual style of the alert. "classic" gives a traditional look, while "default" is a modern design.

shape

Optional

 curve|default

Controls the shape of the alert. "curve" applies rounded corners, while "default" uses standard corners.

positionX

Optional

 left|right

Determines the horizontal position of the alert on the screen. "left" aligns it to the left, "right" to the right.

positionY

Optional

 top|bottom

Determines the vertical position of the alert. "top" places it at the top of the screen, and "bottom" places it at the bottom.

icon

Optional

 string

Specifies a Font Awesome class to use for the icon inside the alert (e.g., fa-check, fa-exclamation).

zenClass

Optional

 string

Allows overriding default styles by passing Tailwind CSS classes. Utilize the ngx-zen/tailwind plugin to target specific elements within the alert component. PS: Only accepts padding styling for the alert component

Events

Event Actions
dismiss

Triggered when the alert is closed or dismissed by the user. You can handle this event to perform actions like removing the alert from the UI or logging the dismissal.
