Properties

Parameter Required Accepted values Usage
title

Required

 string

Sets the title of the table section.
subtitle

Optional

 string

Sets the subtitle text of the table section.
disabled

Optional

 boolean

Disables the table, preventing it from being interacted with.
size

Optional

 compact | default | large

Sets the padding and font size for the table content. compact reduces padding, while large increases it.

shape

Optional

 default | curve

Defines the shape of the table edges. The curve option applies rounded corners to the table.

transition

Optional

 smooth | snappy | none

Sets the transition effect for table interactions. smooth offers a gradual transition, snappy is quicker, and none removes the transition effect.

zenClass

Optional

 string (CSS classes)

Applies custom styles to the outer wrapper of the table. Allows custom control over styling such as colors and padding.

Events

Event Actions
sort

Triggered when a sortable column is clicked. Returns the column field and sort direction.

select

Triggered when a row is selected in a selectable table. Returns the selected state and row data.
