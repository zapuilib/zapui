Getting Started

To get started, please initialised the tailwind library in your angular project. Install tailwindcss via npm, and create your tailwind.config.js file.

Add the paths to all of your template files in your tailwind.config.js file.

Add the tailwind directives for each of Tailwind's layers to your main CSS file.

Import ngx-zen/tailwindplugin for tailwind utilities into your tailwind.config.js file.

Import NgxZenModule from the ngx-zen in your app module or individual component if you're using standalone component, you will also need to import CommonModule & ReactiveFormsModule when you start working with form elements
