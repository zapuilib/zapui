Properties

Parameter Required Accepted values Usage
shape

Optional

 curve|default

Defines the button shape. "Curve" has rounded corners, and "default" is a classic square-cornered button.

size

Optional

 small|wide|wider|default

Controls button sizing. "Small" has slightly bigger width than default, "wide" has more width than small and "wider" has more width than wide.

style

Optional

 classic|noblur

Defines background blur. "Noblur" removes the background blur.
zenClass

Optional

 string

Allows overriding default styles by passing Tailwind CSS classes. Utilize the ngx-zen/tailwind plugin to target specific elements within the alert component.

Events

Event Actions
close

Triggered when the modal is closed or dismissed by the user. You can handle this event to perform actions like removing the component from the UI or logging the dismissal.

Zen Classes

Prefixes Usage
handler

Accepts Tailwind CSS classes for the handler.
modal

Accepts Tailwind CSS classes for the modal, can be used to style custom width, colors and more.

wrapper

Accepts Tailwind CSS classes for the modal wrapper, can be used to style the background and more.
