Properties

Parameter Required Accepted values Usage
data

Required

 any[]

The data to be displayed in the table.
zenClass

Optional

 string

Additional CSS classes to be applied to the table.
size

Optional

 compact | default | large

Sets the size of the table cells. Default is default.
shape

Optional

 default | curve

Defines the shape of the table edges. The curve option applies rounded corners to the table.
striped

Optional

 boolean

Applies alternating background colors to table rows when set to true.
hoverable

Optional

 boolean

Applies a hover effect to table rows when set to true.
borderless

Optional

 boolean

Removes borders from the table when set to true.
searchable

Optional

 boolean

Adds a search input to filter table rows when set to true.
selectable

Optional

 boolean

Adds checkboxes for row selection when set to true.

Events

Event Actions
sortChange

Emitted when a column is sorted. Provides the column field and sort direction.

rowClick

Emitted when a row is clicked. Provides the clicked row data.

selectionChange

Emitted when row selection changes. Provides an array of selected rows.
