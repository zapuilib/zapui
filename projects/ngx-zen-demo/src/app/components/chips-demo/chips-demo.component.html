Chips

@for(item of markdowns; track item; let i = $index) { }

Properties

Parameter Required Accepted values Usage
type

Optional

 primary|secondary|success|error|warning|info|filled|gradient|ghost

Defines the chip's color theme. Defaults to "primary" if not specified.

variant

Optional

 outlined|default

Defines the chip style. "Outlined" is a bordered chip, and "default" is the standard chip.

size

Optional

 small|medium|large

Defines the size of the chip. Defaults to "medium" if not specified.

icon

Optional

 string

Specifies the icon class to be used (e.g., "fa-user" for Font Awesome icons).

iconPosition

Optional

 left|right

Specifies the position of the icon. Defaults to "left" if not specified.

avatar

Optional

 string

Specifies the URL of the avatar image to be displayed in the chip.

status

Optional

 online|offline

Adds a status indicator to the chip.

removable

Optional

 boolean

If set to true, adds a remove button to the chip.

disabled

Optional

 boolean

If set to true, disables the chip and prevents user interaction.

zenClass

Optional

 string

Allows overriding default styles by passing Tailwind CSS classes. Utilize the ngx-zen/tailwind plugin to target specific elements within the chip component.
