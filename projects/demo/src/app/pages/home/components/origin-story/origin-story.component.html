Origin story
What's behind zap ui and why did we get here?
Having worked extensively with the Angular framework, we've noticed a recurring pattern: many components are reused across different projects in one way or another. This led us to wonder—why not use a pre-built library to streamline our workflow and save time? We began searching for libraries on the internet that align with our needs, particularly ones built with Tailwind as the base styling framework we with Tailwind as the base styling framework we prefer. While we found a few options, they fell short in several ways. Many libraries had outdated styling, lacked in-built functionality for essential components like form fields, and offered far fewer options compared to those available for React, Vue etc.
