Properties

Parameter Required Accepted values Usage
variant Optional outlined|default Defines the chip style. "Outlined" is a bordered chip, and "default" is the standard chip.
size Optional small|wide|wider Defines the size of the chip. Defaults to "medium" if not specified.
icon Optional string Specifies the icon class to be used (e.g., "fa-user" for Font Awesome icons).
iconPosition Optional left|right Specifies the position of the icon. Defaults to "left" if not specified.
removable Optional boolean If set to true, adds a remove button to the chip.
disabled Optional boolean If set to true, disables the chip and prevents user interaction.
zenClass Optional string Allows overriding default styles by passing Tailwind CSS classes. Utilize the ngx-zen/tailwind plugin to target specific elements within the chip component.
