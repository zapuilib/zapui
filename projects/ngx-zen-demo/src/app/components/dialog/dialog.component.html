Properties

Parameter Required Accepted values Usage
title

Required

 string

Accepts a title for the dialog.
text

Optional

 string

Accepts a message for the dialog. Don't provide this property if you want to use custom html with the ng-content

shape

Optional

 curve|default

Controls the shape of the dialog. "curve" applies rounded corners, while "default" uses standard corners.

zenClass

Optional

 string

Allows overriding default styles by passing Tailwind CSS classes. Utilize the ngx-zen/tailwind plugin to target specific elements within the dialog component.

Events

Event Actions
confirm

Triggered when the user confirms the action. You can handle this event to perform actions.

cancel

Triggered when the user cancels the action. You can handle this event to perform actions.
