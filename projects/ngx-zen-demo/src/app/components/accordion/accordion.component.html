Accordions

Properties

Parameter Required Accepted values Usage
title

Required

 string

Sets the title of the accordion section.
isOpen

Optional

 boolean

Controls the initial open state of the accordion. Defaults to false.
size

Optional

 compact | default | large

Sets the padding and font size for the accordion.
shape

Optional

 default | curve

Defines the shape of the accordion edges. curve adds rounded corners.
transition

Optional

 smooth | snappy | none

Sets the transition effect for opening and closing the accordion.
iconPosition

Optional

 left | right

Specifies the position of the accordion icon.
openIcon

Optional

 string (icon class)

Specifies the icon to display when the accordion is open. Default is fa-minus.
closeIcon

Optional

 string (icon class)

Specifies the icon to display when the accordion is closed. Default is fa-plus.
zenClass

Optional

 string (CSS classes)

Applies custom styles to the outer wrapper of the accordion.
zenHeaderClass

Optional

 string (CSS classes)

Applies custom styles to the header section of the accordion.
zenContentClass

Optional

 string (CSS classes)

Applies custom styles to the content section of the accordion.

Events

Event Actions
toggle

Triggered each time the accordion is opened or closed. You can handle this event to perform actions such as logging the accordion state or loading dynamic content.
