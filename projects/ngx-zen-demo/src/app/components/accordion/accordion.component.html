Properties

Parameter Required Accepted values Usage
title

Required

 string

Sets the title of the accordion section.
isOpen

Optional

 boolean

Controls the initial open state of the accordion. Defaults to false.
size

Optional

 compact | default | large

Sets the padding and font size for the accordion content. compact reduces padding, while large increases it.
shape

Optional

 default | curve

Defines the shape of the accordion edges. The curve option applies rounded corners to the accordion.
transition

Optional

 smooth | snappy | none

Sets the transition effect for expanding and collapsing the accordion content. smooth offers a gradual transition, snappy is quicker, and none removes the transition effect.
iconPosition

Optional

 left | right

Specifies the position of the accordion icon relative to the title. Defaults to right.
openIcon

Optional

 string (icon class)

Sets the icon displayed when the accordion is open. Default is fa-minus. Accepts any valid Font Awesome or custom icon class.
closeIcon

Optional

 string (icon class)

Sets the icon displayed when the accordion is closed. Default is fa-plus. Accepts any valid Font Awesome or custom icon class.
zenClass

Optional

 string (CSS classes)

Applies custom styles to the outer wrapper of the accordion. Allows custom control over styling such as colors and padding.

Events

Event Actions
toggle

Triggered each time the accordion is opened or closed. You can handle this event to perform actions such as logging the accordion state or loading dynamic content.
