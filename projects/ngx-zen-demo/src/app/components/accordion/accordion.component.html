Properties

Parameter Required Accepted values Usage
title

Required

 string

Sets the title of the accordion section.
isOpen

Optional

 boolean

Controls the initial open state of the accordion. Defaults to false.

size

Optional

 compact|default|large

Sets the padding and font size for the accordion.

shape

Optional

 square|rounded

Defines the shape of the accordion edges.

transition

Optional

 smooth|snappy|none

Sets the transition effect for opening and closing the accordion.

iconPosition

Optional

 left|right

Specifies the position of the accordion icon.

Events

Event Actions
toggle

Triggered each time the accordion is opened or closed. You can handle this event to perform actions such as logging the accordion state or loading dynamic content.
