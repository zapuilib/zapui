Buttons

@for(item of markdowns; track item; let i = $index) { }

Properties

Parameter Required Accepted values Usage
shape

Optional

 pill|curve|default

Defines the button shape. "Pill" is a fully rounded button, "curve" has rounded corners, and "default" is a classic square-cornered button.

size

Optional

 compact|wide|tight|default

Controls button sizing. "Compact" has less padding, "tight" has even smaller padding and fonts (ideal for tab buttons), "wide" spans the full width of the parent container, and "default" follows the standard theme.

type

Optional

 icononly|default

Use "icononly" if the button contains only an icon (requires the icon parameter). "Default" includes both icon and text.

icon

Optional

 string

Specifies a Font Awesome class for the button's icon (e.g., fa-plus).

iconPosition

Optional

 left|right

Sets the icon's position relative to the button text. Defaults to "left". Not required for "icononly" buttons.

variant

Optional

 outlined|default|link

Defines the button style. "Outlined" is a bordered button, "link" creates an underlined link-style button, and "default" is the standard button.

zenClass

Optional

 string

Allows overriding default styles by passing Tailwind CSS classes. Utilize the ngx-zen/tailwind plugin to target specific elements within the alert component.
